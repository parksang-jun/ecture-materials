# 강의자료 — 「원자력과 탄소중립」 초등 3~4학년 발표 (A안 / B안)

초등학교 3~4학년 대상 원자력 발표 자료입니다.
한국원자력연구원의 「원자력 표준 강의안」을 초등학생 눈높이에 맞게 재구성했으며, **서로 다른 콘셉트의 두 가지 버전**을 비교해서 사용할 수 있습니다.

## 🆚 두 버전 비교

| | **A안: 반짝반짝 원자력 세상** | **B안: 1일 어린이 연구원 (상세판)** |
|---|---|---|
| 분량 | 33장 (30~40분) | 53장 (55~65분) |
| 콘셉트 | 5코스 과학 탐험 | 원자력연구원 견학 (1일 연구원 임명) |
| 구성 | 에너지 → 원자 → 발전소 → 안전 → 미래 | ①연구원이 하는 일 ②원자력 기초·발견의 역사 ③원자력 이용 ④**지구를 지켜라! 탄소중립** ⑤미래 기술 ⑥어린이의 미래 역할 |
| 역사 | 간단한 타임라인 | **실제 과학자 사진 6인** (뢴트겐·퀴리·아인슈타인·러더포드·채드윅·한&마이트너) + 인물별 상세 페이지 |
| 사진 | 도형/이모지 일러스트 | **실제 사진 12장** (최초의 X선 사진, CP-1→고리→바라카, 화성 로버, KSTAR) |
| 디자인 | 밝은 화이트 + 파스텔 | 다크 네이비 + 네온 (실험실 느낌) |
| 퀴즈 | 동물 친구가 출제 (8개) | 어린이 연구원 자격 시험 (12개, 고민형) |
| 마무리 | 오늘 배운 것 정리 | 어린이 연구원 수료식 |

두 버전 모두: 16:9, 두 장마다 미니 퀴즈, 유튜브 영상 슬라이드(발전소 영상은 서울시교육청 융합과학교육원 공식 영상), 슬라이드별 발표자 노트(스크립트) 포함.

## 사용 방법

- 발표 시 PowerPoint **발표자 보기**를 켜면 각 슬라이드의 스크립트가 노트로 표시됩니다.
- 영상 슬라이드의 카드를 클릭하면 유튜브로 이동합니다. (A안: 16·19·31·32번 / B안: 14·17·27·31번)
- 영상 검색 카드에는 유튜브의 **"4분 이내 영상만 보기" 필터**가 걸려 있어 짧고 쉬운 영상만 나옵니다.
- 유튜브 영상은 삭제·변경될 수 있으니 **수업 전날 링크를 한 번씩 확인**하고 보여줄 영상을 미리 골라 두세요.
